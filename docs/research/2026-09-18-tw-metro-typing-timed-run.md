# Taiwan Metro Typing: timed-run Terminus behavior

Source inspected: [`ridemountainpig/tw-metro-typing` at commit `dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246`](https://github.com/ridemountainpig/tw-metro-typing/tree/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246). This note describes its implementation, not a proposed rule for MyRapid Typing.

## Findings

- The comparable mode is called `timed` in code and **30 秒** (30 seconds) in the UI. Its duration is a fixed 30,000 ms, independent of Line or number of Stations. The timer finishes the Run at that limit. [Mode picker](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/components/HomeScreen.jsx#L367-L371) · [duration and timer](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/App.jsx#L25-L25) · [finish condition](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/App.jsx#L191-L203)
- The player can choose a service-pattern Run and forward or reverse Direction. The playable sequence is the selected Run's full Station list, reversed if requested. There is **no random starting Station**: starting or retrying resets `stationIndex` to zero, so play begins at the chosen Direction's origin Terminus. [Run/Direction controls](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/components/HomeScreen.jsx#L104-L136) · [Direction choices](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/components/HomeScreen.jsx#L317-L357) · [sequence construction](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/lib/map.js#L115-L150) · [start reset](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/App.jsx#L135-L150)
- On completion of the final Station, **full-Line mode ends**, but timed mode does not. Both modes count that Station; only timed mode then computes `(currentIndex + 1) % stations.length`, which makes the first Station the next typing target. Thus timed play repeats the same sequence until the 30-second timer expires. It does **not reverse Direction** at the Terminus or shorten the timer for a short Line. [Advance rule](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/App.jsx#L205-L217) · [timer rule](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/App.jsx#L200-L203)
- The final Station is visibly marked as the Terminus, with no next Station; the train's progress is zero at that point. After wrap, the map derives the train position from Station zero and rebuilds the progress path from the start. **Inference from render code:** the train and progress line jump back to the origin; this is not a simulated return journey or a verified animation observation. The Direction label still names the original destination. [Station card and Direction label](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/components/GameScreen.jsx#L24-L29) · [Terminus presentation](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/components/GameScreen.jsx#L45-L79) · [map position and progress](https://github.com/ridemountainpig/tw-metro-typing/blob/dc4864dd02e7f492e03b2a0f928e1d1f7a5ba246/src/components/MetroMap.jsx#L51-L89)

## Relevance to MyRapid Typing

This reference avoids a Run *starting close to* a Terminus by always starting at the selected Direction's origin. It does not solve a fast player reaching the destination Terminus before time expires: it repeats the Line from the origin, with an abrupt map reset. Adopting only its starting rule could reduce early repetition, but adopting its wrap rule would preserve the repetitive behavior reported for MR. This comparison is an inference from the rules above, not a recommendation to copy the reference implementation.
